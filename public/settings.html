设置

配置 AI 联网搜索的接口与密钥。配置保存在服务端本地文件（.settings.json），已被 gitignore 保护，不会进入代码仓库

AI 联网搜索（LLM）

兼容 OpenAI Chat Completions 协议的任意接口。配置后，景点页即可选择「AI 联网搜索」。

高德地图（可选）

配置后，服务端「自动」降级链将优先使用高德真实 POI 数据（含评分、人均消费、照片），供景点与美食餐厅使用。申请 Web 服务 Key

机票实时数据 · Amadeus（可选）

配置后车票页机票将使用 Amadeus 实时报价（真实班次 / 时刻 / 含税总价）。 在 Amadeus 开发者平台免费注册，创建 Flight Offers Search 应用即可获得凭据（测试环境每月有免费额度）。

说明

  • 配置优先级：本页保存的配置 > 服务端 .env 环境变量 > 默认值。
  • API Key 仅保存在服务端本地，接口返回时自动脱敏（如 sk-KA***xxxx），不会明文回显。
  • 保存后景点 / 酒店 / 美食 / 机票缓存会自动清空，下次搜索立即使用新配置。
  • AI 联网搜索需实时生成内容，约需 10~40 秒；本地数据秒开但仅覆盖 25 个热门城市。
